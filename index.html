How it's secured

  • Zero-trust access

    Anything reachable from outside sits behind Cloudflare Zero Trust. Every request is authenticated at the edge before it ever reaches the home network, and only approved identities get in, with a one-time code.

  • No inbound ports

    Nothing is port-forwarded. Services reach the internet through outbound-only Cloudflare Tunnels, so the home network accepts no inbound connections.

  • Mutual TLS

    Mobile clients require a client certificate on each device. Requests without a valid certificate are dropped at the edge, and any device can be revoked on its own.

  • Defence in depth

    Passing the edge only gets you to each app's own login. No single control stands between the internet and the data.

  • Geo-fencing

    A web application firewall rule blocks traffic from outside my country.

  • Least exposure

    Services stay on the home network by default. Nothing is reachable from outside unless it has a reason to be.

  • Encryption in transit

    TLS everywhere, including on the LAN, with a wildcard certificate issued through a DNS challenge so nothing has to be exposed to get it.

  • Patch management

    Apps and containers update automatically, and the AI server installs OS security patches on its own.
